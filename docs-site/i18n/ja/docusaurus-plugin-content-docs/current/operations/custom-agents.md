# カスタムエージェントとスキル

**連携 → Agents & Skills → Custom Agents & Skills** で管理します。管理者権限が必要です。エージェントは診断の観点と既存ゲートウェイを、スキルは再利用する Markdown 指示を定義します。登録だけではコードのインストールや外部のマネージドエージェントへの接続は行いません。

## 登録から利用まで

1. **New Agent** に kebab-case の名前、説明、ペルソナ、ゲートウェイ、ルーティングキーワードを入力します。外部可観測性ゲートウェイの `observability` も選択できます。
2. **New Skill** に名前、説明、Markdown 指示を入力します。根拠の使用条件と未確認範囲の示し方を具体的に記述してください。
3. 新規・置換されたカスタム項目は **Disabled** です。スキルを有効にしてから、エージェントのスキル選択欄で関連付けます。一覧には合成順で表示されます。
4. エージェントを有効にします。アカウントに **Agent Space** がある場合は、その選択にも含めてください。アカウントのツール上限は利用可能なツールを絞り込みます。登録によってインフラ権限は増えません。
5. ハイブリッドルーティングを利用できる環境では、アシスタントに `/` を入力し、現在のアカウントで有効なカスタムエージェントを選択して質問を送信します。キーワードによる自動選択も利用できます。アカウント範囲を変えると選択したカスタムコマンドは解除され、送信時にサーバーが有効状態を再確認します。

組み込み項目はこの画面から置換・切り替えできません。既存のカスタム名で保存すると定義を置換して無効にするため、確認後に再び有効にしてください。

## ペルソナの例

| 目的 | ゲートウェイ | 指示の内容 |
|---|---|---|
| SRE 調査 | `ops` | 根拠と観測時刻を示し、仮説・影響・次の読取確認を分ける。 |
| IAM レビュー | `security` | 信頼境界と権限の根拠を説明し、未評価の統制を示す。 |
| FinOps レビュー | `cost` | 削減額の見積もり前に請求期間・使用率・コミットメントを確認する。 |

これらは AWSops 内のペルソナです。AWS DevOps Agent と AWS Security Agent は別サービスであり、登録によって作成・呼び出しされません。

## データとナレッジの接続

Datadog・Dynatrace などは **連携 → Datasources** に登録します。Notion の認証情報や対応する hosted MCP の事前設定は **Connectors** で管理します。認証情報の保存は接続確認とは異なります。任意の MCP エンドポイントや自律的なインフラ変更は有効になりません。
