# 커스텀 에이전트와 스킬

**연동 → Agents & Skills → Custom Agents & Skills**에서 관리합니다. 관리자 권한이 필요합니다. 에이전트는 진단 관점과 기존 게이트웨이를, 스킬은 재사용할 Markdown 지침을 정의합니다. 등록으로 실행 코드를 설치하거나 외부 관리형 에이전트에 접속하지는 않습니다.

## 등록 후 사용하기

1. **New Agent**에 kebab-case 이름, 설명, 페르소나, 게이트웨이, 라우팅 키워드를 입력합니다. 외부 관측성 게이트웨이를 사용하는 `observability`도 선택할 수 있습니다.
2. **New Skill**에 이름, 설명, Markdown 지침을 입력합니다. 근거를 언제 사용하고 미확인 범위를 어떻게 표시할지 구체적으로 작성하세요.
3. 새로 저장하거나 교체한 커스텀 항목은 **Disabled**입니다. 스킬을 활성화하고 에이전트의 스킬 선택 목록에서 연결합니다. 연결된 스킬은 합성 순서대로 표시됩니다.
4. 에이전트를 활성화합니다. 계정에 **Agent Space**가 있으면 해당 계정의 에이전트 선택에도 포함하세요. 계정의 도구 제한은 게이트웨이 도구를 줄일 수 있으며, 등록으로 인프라 권한이 늘어나지 않습니다.
5. 하이브리드 라우팅을 사용할 수 있는 배포에서는 어시스턴트에 `/`를 입력해 현재 계정의 활성 커스텀 에이전트를 선택하고 질문을 보냅니다. 키워드 자동 선택도 지원합니다. 계정 범위를 바꾸면 선택한 커스텀 명령이 해제되며, 전송 시 서버가 활성 상태를 다시 확인합니다.

기본 제공 항목은 이 화면에서 교체하거나 활성 상태를 바꿀 수 없습니다. 기존 커스텀 이름으로 저장하면 정의를 교체하고 비활성 상태가 되므로 다시 검토한 후 활성화하세요.

## 시작하기 좋은 페르소나

| 목적 | 게이트웨이 | 포함할 지침 |
|---|---|---|
| SRE 조사 | `ops` | 근거와 관측 시간을 명시하고 가설·영향·다음 읽기 전용 확인을 구분합니다. |
| IAM 검토 | `security` | 신뢰 경계와 권한 근거를 설명하고 미평가 통제를 표시합니다. |
| FinOps 검토 | `cost` | 절감액을 추정하기 전에 청구 기간·사용률·약정을 확인합니다. |

이들은 AWSops 내부 페르소나입니다. AWS DevOps Agent와 AWS Security Agent는 별도 서비스이며 페르소나 등록으로 생성되거나 호출되지 않습니다.

## 데이터와 지식 연결

Datadog·Dynatrace 등은 **연동 → Datasources**에서 등록합니다. Notion 자격증명과 지원하는 hosted MCP의 사전 설정은 **Connectors**에서 관리합니다. 자격증명 저장은 접속 확인과 다릅니다. 커스텀 에이전트 등록으로 임의 MCP 엔드포인트나 자율 인프라 변경이 활성화되지 않습니다.
