# Historical evidence

This tree retains dated plans, reviews, prototypes and execution records in their
original language. They are not current project instructions, deployment state or
permission to enable features. Read a specific record only when its provenance is
needed; do not load this archive as default PR-review context.

Current decisions: [BASELINE](../decisions/BASELINE.md).
Current implementation: [architecture](../architecture.md) and [references](../reference/README.md).
Legacy ADR lookup: [mapping](../decisions/ADR-MAPPING.md).

Preserve original approval/date/evidence when citing history. Superseded mutation
plans do not override ADR-005, and an old checklist does not certify current health.
