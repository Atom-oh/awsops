# Kiro Review Rules

[AGENTS.md](../AGENTS.md) is the shared reviewer context.
Use the nearest scoped CLAUDE.md or generated AGENTS.md for module details.
Policy comes from root [CLAUDE.md](../CLAUDE.md) and
[BASELINE.md](../docs/decisions/BASELINE.md).

Check the implementation and its callers before reporting a violation. Separate
new regressions from existing limitations and documentation drift. Missing review
coverage or a failed check is not a clean result. Developer and reviewer guidance
is English-only; this does not change product localization.
